# Mensagens Codificadas

## 📜 Sobre o Projeto

O **Mensagens Codificadas** é uma aplicação simples e interativa desenvolvida com HTML, CSS e JavaScript. Ele permite que você **criptografe** e **descriptografe** mensagens de texto de forma prática. O projeto é ideal para quem deseja experimentar a codificação de mensagens de forma divertida e educativa.

---

## 💡 Funcionalidades

- **Criptografar Texto**: Substitui determinadas letras por sequências específicas para codificar a mensagem.  
  Exemplo:  
  - `"e"` → `"enter"`  
  - `"i"` → `"imes"`  
  - `"a"` → `"ai"`  
  - `"o"` → `"ober"`  
  - `"u"` → `"ufat"`

- **Descriptografar Texto**: Reverte a codificação, retornando o texto original.

- **Copiar Mensagem**: Permite copiar a mensagem gerada (criptografada ou descriptografada) com um único clique.

---

## 🛠️ Tecnologias Utilizadas

- **HTML**: Estrutura básica do site.  
- **CSS**: Estilização do layout, utilizando variáveis e responsividade para diferentes dispositivos.  
- **JavaScript**: Lógica das funcionalidades (criptografar, descriptografar e copiar texto).
